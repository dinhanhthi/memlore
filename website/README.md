# Memlore Website

This folder contains the standalone marketing website for Memlore. It is a React + TypeScript + Vite app with its own Vite config, routes, tests, and production build output.

## Local Development Mode

From the repository root:

```bash
# http://127.0.0.1:5174/
pnpm website:dev

# build
pnpm website:build

# preview the production build with a local server
# http://127.0.0.1:4174/
pnpm website:preview

# test
pnpm website:test
```
